## 基础概念

![image-20260429202855106](/assets/img/什么是神经网络-assets/image-20260429202855106.png)

我们有六套房子，现在需要用一个函数，来根据房子的大小预测价格。一般的思路，就是采用线性回归的方式去模拟这个函数，也就是画一条直线，因为我们知道房价是不可能为负数的，所以前面就直接让它归零。这里我们得到的左边为0，右边为直线的方程，称为 ReLU 函数，即线性整流函数（Rectified Linerar Unite rectified linear units）

![image-20260429203032451](/assets/img/什么是神经网络-assets/image-20260429203032451.png)

得到这个函数后，我们输入一个 size（作为x），通过中间这个圆圈的处理，得到一个输出，也就是价格 y，这里我们把这个圆圈称为一个神经元。所有的神经元都会做一件事，就是以 size 作为输入，然后经过函数的计算，输出得到房价 price

![image-20260429203258445](/assets/img/什么是神经网络-assets/image-20260429203258445.png)

这里只是一个单一的神经元，大型神经网络就是由许多单一神经元叠加而成的。假设我们现在不仅知道 size 这一个特征量，我们还知道其他的特征量。

- 根据 size 和卧室的数量，可以估计家庭人口数
- 根据地区的邮政编码，可以估计生活的便利性，比如开车是否方便？是否可以散步？
- 根据邮政编码和该地区的富裕程度，可以估计周围学校的质量

得到的家庭人口数、便利性、学校质量的估计值，都可以帮我们更好的预测房价。所以这里的 x、y 的值分别为：

- x = [size, bedrooms, zip code, wealth]
- y = price

![image-20260429204559923](/assets/img/什么是神经网络-assets/image-20260429204559923.png)

## 神经网络

根据以上，我们可以得到如下：

![image-20260429204858520](/assets/img/什么是神经网络-assets/image-20260429204858520.png)

神经网络的工作就是预测 y ，我们输入确定的 x （x = [x1,x2,x3,x4]），神经网络帮我们预测出 y 值。中间的神经元，叫做隐藏神经元

![image-20260429205033398](/assets/img/什么是神经网络-assets/image-20260429205033398.png)

但是在我们之前的分析，决定 family size 的，只有 x1、x2 ，但是这里每个隐藏神经元都把 [x1,x2,x3,x4] 作为输入，这是为什么？当然是让神经网络自己去决定，需要哪些特征值，反正我给你的是所有，也就是 [x1,x2,x3,x4] ，你自己决定需要哪些。

当我们给出的 (x,y) 真实数据集合够多的时候，神经网络就能很好的拟合出一个函数来建立 x 和 y 之间的映射关系。所谓监督学习，就是把一个 x 和一个 y 给对应起来。

## 监督学习与神经网络

神经网络，neural network ，以下简称 NN

### 监督学习的利用场景

监督学习(Supervised Learining)

![image-20260429210847985](/assets/img/什么是神经网络-assets/image-20260429210847985.png)

我们想通过 x 学习到一个函数，这个函数能够将 x 映射成 y 。常见的应用场景有：

1. 预测真实值，就比如上面提到的预测房价

2. 目前用的最多的就是广告，也就是我们说的大数据推荐。根据你的用户信息和在线浏览的网页信息，去预测你最有可能点击的广告

   - Input(x) = Ad, user Info

   - Output(x) = 是否点击广告 (1/0)

3. 还有就是机器视觉，输入图片，输出该图片最有可能的分类，这里假设有 1000 种图片类别，通过机器学习，就可以很好的标记图片类别。
4. 语音识别。也就是语音转文本
5. 机器翻译。English -> Other Language
6. 自动驾驶技术。输入车辆前方的信息的图像、雷达扫描信息，输出路面上其他车辆的信息

使用不同结构的神经网络，并通过监督学习拟合数据，能够很好的解决不同应用领域的问题。

![image-20260429211947336](/assets/img/什么是神经网络-assets/image-20260429211947336.png)

- 对于之前提到的房价预测，我们使用最标准的神经网络
- 对于图像信息，使用卷积结构，即 CNN ，卷积神经网络，Convolutional netural network
- 对于序列化的数据，比如音频，是时序组成的数据，因为音频需要完整的播放才能表达意思，所以，一维时间序列或一维时序序列能很好的代表音频的数据结构。这种我们常用 RNN，即循环神经网络，recurrent netural network；还有汉字，也是在特定的时序中出现，也能自然的表现为序列化数据
- 对于自动驾驶这样的，需要更多的图像信息和别的信息，用到的结构也会更复杂和更加定制化

![image-20260429212051113](/assets/img/什么是神经网络-assets/image-20260429212051113.png)

### 结构化数据与非结构化数据

- 结构化数据：基于数据库的数据 / 列表。即每一个特征变量都有清晰的定义
- 非结构化数据：没有清晰的定义，比如音频、图像、文本信息（人类好理解的）

### 性能

决定性能的三个要素：

- Data ： 数据集
- Computation：计算能力
- Algorithms：算法 --> 让神经网络运行的更快。

#### Data

一般想要更好的性能，要么就是训练更大型的神经网络，要么是用更大量的数据集。所以就两个思路，要么扩大神经网络，要么扩大数据集。但是我们的数据集终究会用完的，或者我们的神经网络太大了，训练会耗费很长时间

![image-20260504202946132](/assets/img/什么是神经网络-assets/image-20260504202946132.png)

那么什么是标记过的数据（labeled data）？

对于训练集，我们同时有 (x,y)，x 是输入， y 是标记。m 是数据集的大小。

![image-20260504204950183](/assets/img/什么是神经网络-assets/image-20260504204950183.png)

如果前面的小型数据集对应的算法性能很高，很有可能是用了 SVM (支持向量机) ，也就是用特定的数据集去训练，那性能肯定好。所以图中左半部分的不同算法的性能排名是不一样的，这个排名更多是由你提取的特征和算法的细节决定的。

#### Algorithms

举个例子，神经网络中的一个重大变化就是激活函数从 sigmoid 函数到 ReLU 函数的迁移。左图是 sigmoid 函数，右图是 ReLU 函数（修正线性单元，rectified linear unit）

![image-20260504210749767](/assets/img/什么是神经网络-assets/image-20260504210749767.png)

sigmoid 函数的问题是，在梯度几乎为 0 的区域，机器学习的进度将会非常慢。

ReLU 对于所有正输入梯度都是1，所以梯度就不会慢慢变成 0
